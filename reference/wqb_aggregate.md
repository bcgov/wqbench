# Aggregate Data for each Species

Aggregate data to select the most sensitive value for each species. The
priority of effect level depends on the benchmark method that will be
used.

## Usage

``` r
wqb_aggregate(data)
```

## Arguments

- data:

  A data frame

## Value

A data frame

## Details

Check the resource document for the rules used to aggregate the data
down to a single value per species. This is Step 5.

## Examples

``` r
if (FALSE) { # \dontrun{
data <- wqb_aggregate(data)
} # }
```
