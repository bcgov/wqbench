# Summary Table of the Assessment Factor Values

Create summary table of the species variation factor, ecological
assessment factor and B.C. species factor.

## Usage

``` r
wqb_summary_af(data)
```

## Arguments

- data:

  A data frame

## Value

A data frame

## Examples

``` r
if (FALSE) { # \dontrun{
summary_af <- wqb_summary_af(data)
} # }
```
