# Filter to a Single Chemical

Filter to a Single Chemical

## Usage

``` r
wqb_filter_chemical(data, cas_num)
```

## Arguments

- data:

  A data frame

- cas_num:

  A string of the cas number.

## Value

A data frame

## Examples

``` r
if (FALSE) { # \dontrun{
data <- wqb_filter_chemical(data, "129909906")
data <- wqb_filter_chemical(data, "1000984359")
} # }
```
