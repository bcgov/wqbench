# Determine the Ecological Assessment Factors

Determines the assessment factor based on the presence of certain
ecological groups.

## Usage

``` r
wqb_af_ecological(data)
```

## Arguments

- data:

  A data frame

## Value

A data frame

## Details

Check the resource document for how the assessment factor was
calculated.

## Examples

``` r
if (FALSE) { # \dontrun{
data <- wqb_af_ecological(data)
} # }
```
