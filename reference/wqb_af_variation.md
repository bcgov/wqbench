# Determine the Species Variation Assessment Factor

Determine the assessment factor based on the number of trophic groups
and species.

## Usage

``` r
wqb_af_variation(data)
```

## Arguments

- data:

  A data frame

## Value

A data frame

## Details

Check the resource document for how the assessment factor was
calculated.

## Examples

``` r
if (FALSE) { # \dontrun{
data <- wqb_af_variation(data)
} # }
```
