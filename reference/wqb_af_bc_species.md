# Determine the BC Species Assessment Factor

Determines an assessment factor based on the number of BC species
present.

## Usage

``` r
wqb_af_bc_species(data)
```

## Arguments

- data:

  A data frame

## Value

A data frame

## Details

Check the resource document for how the assessment factor was
calculated.

## Examples

``` r
if (FALSE) { # \dontrun{
data <- wqb_af_bc_species(data)
} # }
```
